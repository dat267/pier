# Reproduced audit findings
- **A542, low:** a package filter object set through the API is saved with its keys sorted. pi v1.5.2 (b4afdddf) stores package sources as JavaScript objects, so `setProjectPackages([{source: "pkg-b", skills: ["s"]}])` writes `{"source":...,"skills":[...]}` in that order. `coding/settingsmanager.go` `SetPackages`/`SetProjectPackages` take `[]any`, so the caller's object is already a Go map and the write sorts it (`{"skills":...,"source":...}`). No production caller sets packages (the package manager is out of scope, D-rows), so this is reachable only through the library API; a faithful fix needs an order-preserving input (raw JSON or an ordered object), which is an API decision.
