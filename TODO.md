# Reproduced audit findings

- **A526, medium:** `/share` is not implemented, so typing it sends `/share` to the model as a user message (a wasted turn) instead of sharing the session. pi v1.5.2 (b4afdddf) `core/slash-commands.ts` lists it, `modes/interactive/session-share.ts` (`shareSession`) exports the branch with a trailing `pi.share` entry carrying the system prompt and tool schemas, uploads it to Radius (`POST {gateway}/v1/artifacts`, Bearer token) or creates a private gist through `gh gist create` and shows `https://pi.dev/session/#<gistId>`, and `core/settings-manager.ts` `sessionShareDestination` (default `"auto"`, `auto|gist|radius`) selects the route. Pier has the pieces it needs (`coding.ExportToJsonl`, the HTML export, Radius login) but none of the command, the setting or `PI_SHARE_VIEWER_URL`. The other upstream commands pi lacks (`/bug`) are documented out of scope (D41, D316), so this is the only unhandled one.
