# Reproduced audit findings

- M143 (low, performance, open): `ai.MarshalJSON` is now about 11–12 ms and 24k allocations for a 4,000-message conversation (790 KB), down from 90–100 ms and 838k; Node `JSON.stringify` takes 1.1 ms. The normalized-input fast path accounts for the latest reduction, with scalar/content fast paths before it. Bodies that are not already canonical (HTML escapes, reordered index keys, duplicate keys, padded numbers) still take the full parser. A fragment-marshaling path and a decision on whether wire/persisted bytes may skip JS key-order parity would close the rest; realistic sizes cost only a few ms today. See D350.
