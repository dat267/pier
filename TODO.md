# Reproduced audit findings

- M140 (perf): pinned pi v1.5.0 `highlight.js` is faster than pier for an 8 KiB JSON-looking repeated-token input (`"0x"` × 4,096): five warmed Node runs measured 1.90–2.01 ms/op, while pier's unmodified Go path measured 19.82–20.31 ms/op. A byte-buffer prototype reduced pier to 4.8 ms/op but still missed the reference and regressed a representative 8 KiB JSON document (2.8 ms vs 2.6 ms for the original Go path), so it was reverted. The representative document is faster than upstream (2.32–2.51 ms Go vs 4.09–4.15 ms Node). This remains open; no behavior or performance patch accepted until the exact workload beats the reference without regressing representative highlighting. Benchmarks are in `internal/highlight/performance_bench_test.go`.
